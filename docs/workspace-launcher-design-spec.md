# 工作区启动器（WorkspaceSelector）改版 · 设计规格

> **状态：已锁定** · 2026-08-12
> **方向：A 增强版** — 卡片网格 + 品牌语境面板 + 动态背景 + 响应式
> **可视化参考**：`workspace-launcher-redesign.html`（Open Design 工作区，可交互）
> **目标文件**：`gui/src/components/chat/WorkspaceSelector.tsx`

---

## 1. 决策背景

现有启动器为「居中窄卡片 + 纯文本路径列表 + 三控件新建」，存在三个问题：

1. 纯文本路径列表，无名称 / 层级 / 时间信息，信息密度极低；
2. 新建流程（输入框 + 浏览 + 添加）拥挤，无引导、无回车确认；
3. 作为每次启动的第一屏，缺乏品牌感与产品质感，大屏下空旷。

对比三个方向（A 卡片网格 / B 列表+详情 / C 聚焦启动器）后，**锁定 A**：

- B 的详情面板依赖后端运行数据（后端状态、会话数等），需新增接口，落地成本高，不采纳；
- C 的键盘交互作为后续增强可叠加，不阻塞本方案。

## 2. 设计原则（锁定）

1. **数据诚实**：状态区如实反映「连接在选择工作区后才建立」，不得谎称"已连接"；不虚构工作区数据。
2. **无需新增接口**：卡片只展示路径本身可得的信息（名称 / 路径 / 当前标识）。
3. **视觉契约不变**：严格绑定 `gui/src/tokens.css`，不引入新色值 / 新字体 / 新品牌。
4. **大屏填充有依据**：品牌面板与动态背景均与产品语境相关，不做无意义点缀。
5. **对话预览用 GUI 形态**：聊天气泡风格，不用 CLI 终端提示符。

## 3. 布局与响应式

```
大屏（容器 > 980px）
┌───────────────┬────────────────────────────────────┐
│ 品牌语境面板  │  搜索框                              │
│ · Logo/版本   │  ┌────────┬────────┐ ┌───────┐      │
│ · 对话预览    │  │ 工作区  │ 工作区  │ │ 新建  │      │
│ · 连接状态    │  ├────────┼────────┤ │ ───── │      │
│ · 提示        │  │ 工作区  │ 工作区  │ │ (虚线) │      │
│               │  └────────┴────────┘ └───────┘      │
│               │  ─────────────────────────────────── │
│               │  即将启动：<名>        [启动工作区]   │
└───────────────┴────────────────────────────────────┘

窄屏（容器 ≤ 980px）：隐藏品牌语境面板，卡片网格独占整窗
超窄（容器 ≤ 640px）：卡片网格降为单列
```

实现方式：容器查询 `container-type: inline-size` 挂在启动器根节点（Tauri WebView 为较新 Chromium，支持）。

## 4. 组成模块规格

### 4.1 品牌语境面板（左栏）

| 区块 | 内容 | 数据来源 |
|------|------|----------|
| 品牌标识 | 强调色圆角方块 + prompt 图标 + 「Claude Code Desktop」+ Preview | 静态 |
| 对话预览 | GUI 聊天气泡：用户消息（右侧、`--accent-subtle` 底）→ AI 思考（三点动画）→ AI 回复逐字打出 | 静态示例，循环播放 |
| 连接状态卡 | 见 §4.4 | settings（地址配置） |
| 快捷提示 | 「按 F1 打开命令面板，Ctrl+Shift+P 快速切换工作区」 | 静态 |

### 4.2 工作区卡片网格（右栏）

- **搜索框**：实时过滤（按名称 + 路径），`:focus-within` 高亮。
- **卡片**（2 列网格，窄屏单列）：
  - 文件夹图标（强调色浅底）；
  - 工作区名称（basename，加粗，超长省略）；
  - 「当前」徽标（`activeWorkDir` 命中时）；
  - 完整路径（等宽字体，超长省略）；
  - hover 显示删除按钮（hover 卡片时淡入，悬停变错误色）。
- **新建工作区卡片**（虚线）：点击展开内联添加面板（路径输入 + 浏览 + 取消 + 添加；Enter 确认、Esc 取消）。
- **空态**：列表为空显示「还没有工作区」；搜索无匹配显示「没有匹配的工作区」。
- **底部操作栏**：`即将启动：<名称>` + 主按钮「启动工作区」（唯一主 CTA，未选中时禁用）。

### 4.3 对话预览（GUI 聊天气泡）

- 用户消息：右对齐、`--accent-subtle` 底、右下小圆角气泡。
- AI 消息：左对齐、`--bg-root` 卡片 + 左侧品牌小图标、左上小圆角。
- 动画序列循环：用户消息 → AI「思考中」三点 → AI 回复逐字打印 + 光标闪烁。
- `prefers-reduced-motion` 时禁用打字/闪烁动画（直接显示完整回复）。

### 4.4 连接状态卡（诚实性约定）

标题固定为 **「连接与本地数据 · 选择工作区后建立」**。三项均为中性徽标（非绿色"已连接"）：

| 项 | 副行 | 徽标 |
|----|------|------|
| 更新 / 技能服务器 | 内网 96 · 地址已配置 | 配置就绪 |
| 后端 IDE 进程 | 每工作区独立 · claude.exe | 选择后启动 |
| 本地数据 · 记忆 MCP | 会话 / 桌面 / 笔记 | 选择后建立 |

## 5. 数据需求与契约

| 数据 | 现状 | 本方案 | 说明 |
|------|------|--------|------|
| `workspaces: string[]` | ✓ | 必需 | 已有 |
| `activeWorkDir: string` | ✓ | 必需 | 已有 |
| 名称（basename） | ✗ | 前端解析 | `path.split(/[\\/]/).pop()`，无需接口 |
| 最近打开时间 | ✗ | **可选** | `recentWorkspaces` 目前为 `string[]` 无时间戳；v1 省略时间行 |
| 后端状态 / 会话数 | ✗ | **不做** | B 方向需求，本方案明确不依赖 |

## 6. 视觉规范

- 颜色、字体（Segoe UI / Microsoft YaHei）、圆角、阴影：全部绑定 `tokens.css`，深浅双主题自动生效。
- 强调色（`--accent`）每屏不超过两处；主 CTA 唯一（启动工作区）。
- 背景：`--grid-dot` 点阵网格 + 两团缓慢漂移的强调色光晕（`blur` 大半径、低透明度），静态层 + 动画层分离。
- 交互态：卡片 hover 抬升 + 强调色边框；选中卡片强调色边框 + `--accent-subtle` 底；聚焦元素保留 `:focus-visible` 光圈。
- 键盘：新建面板支持 Enter 确认、Esc 取消。

## 7. 文案（i18n 新增 `workspace.*`）

见 `gui/src/i18n/{zh,en}.ts` 中 `workspace` 对象：新增 `searchPlaceholder`、`currentBadge`、`newCard`、`newPath`、`addWorkspace`、`cancel`、`launching`（`{name}` 参数）、`selectWorkspace`、`noMatch`、`previewBadge`、`chatPreview`、`chatUser`、`chatAnswer`、`connTitle`、`connServer*`、`connBackend*`、`connLocal*`、`tipShortcuts`；更新 `subtitle`、`launch`。

## 8. 实现范围

- **文件**：`WorkspaceSelector.tsx`（重写渲染层）、`i18n/{zh,en}.ts`（新增文案）、`tokens.css` 无改动。
- 动画：纯 CSS（点阵/光晕/光标/三点）+ 组件内一次性注入 `<style>`（keyframes + `@container`）；打字用 `setTimeout` 递归，`prefers-reduced-motion` 时跳过。
- 布局：容器查询响应式；不引入第三方库。
- 删除工作区仅改前端列表，不删磁盘目录（与现状一致）。

## 9. 验收清单

- [ ] 大屏显示品牌面板 + 卡片网格；窄屏（≤980px）仅显示卡片网格；≤640px 单列。
- [ ] 搜索实时过滤；卡片选中/启动/删除/新建流程可用。
- [ ] 状态区为中性徽标，无"已连接"字样；对话预览为聊天气泡非 CLI 终端。
- [ ] 深浅主题均正常，无低对比度问题（文字 ≥ 4.5:1）。
- [ ] `prefers-reduced-motion` 下无动画。
- [ ] 无新增后端接口；未绑定工作区时无任何连接断言。
- [ ] 文件无占位符、无空白段落。

## 10. 明确不做（非目标）

- B 方向的详情面板（后端状态 / 会话数等需接口的数据）。
- 键盘导航（C 方向，作为后续增强叠加，不阻塞本方案）。
- 修改布局持久化 / 多实例 / 绑定流程等既有机制。
