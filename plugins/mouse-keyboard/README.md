# 鼠标键盘

让 AI 能**操作**你的电脑 —— 移动鼠标、点击、拖拽、滚动、按键、输入文字。装上之后你对 AI 说「帮我把那个对话框关掉」「在搜索框里输入 xxx」，它就能自己动手。

> ⚠️ 这是**能改变系统状态**的能力，和只读的截屏插件根本不同 —— AI 能点任何按钮、在任何窗口打字。所以本插件在"可控"上做了不少设计，见下方「安全设计」。使用前请先读一遍。

## 能做什么

AI 拿到**一个工具** `plugin_mouse_keyboard_control`，用 `action` 参数区分操作：

| action | 作用 |
|---|---|
| `screen_info` | 返回所有显示器与鼠标当前位置（**AI 调用的第一步**，用来校准坐标） |
| `move` | 移动鼠标 |
| `click` | 单击 / 双击 / 右键（不给坐标就点当前位置） |
| `drag` | 从 A 按住拖到 B |
| `scroll` | 滚轮（正 dy 向下、正 dx 向右） |
| `key` | 按键 / 组合键（`ctrl+a`、`alt+tab`、`f5`…） |
| `type` | 输入文字（**中文可以**，走 Unicode 直发、绕过输入法） |
| `abort` | 让 AI 自己喊停 |

在面板里你可以手动试这些操作，不需要 AI 也能验证插件是否正常。

## 安全设计

### 一、三层急停（任何时候都能停）

| 方式 | 说明 |
|---|---|
| **按住急停键** | 默认 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>F12</kbd>，**不需要本窗口在前台**，在任何程序里按都有效 |
| **面板停止按钮** | 面板里那个大红色按钮 |
| **AI 自己喊停** | AI 发现做错了会调 `abort` |

急停后**不会自动恢复** —— 后续操作一律被拒（AI 会看到"已急停"的提示），要你**在面板里点「解除急停」**才能继续。这样你按下急停之后可以放心去检查发生了什么。

> 为什么急停用"按住组合键"而不是注册系统级热键：系统级热键是**整个系统独占**的，开多个 GUI 时只有先启动的那个能用 —— 而急停必须**任何情况都能用**。轮询按键不抢键、每个窗口各自有效。

### 二、AI 不能操作本应用（默认开）

如果本应用窗口在最前面，AI 的操作会被**拒绝**。

这条不是洁癖：AI 的工具权限确认框就是普通窗口按钮 —— 没有这道防线，AI 可以一边调用工具弹出确认框、一边点「允许」，**用它的权限框给自己授权**，完全绕过"需要你确认"这件事。可以在设置里关掉，但不建议。

### 三、按键不会卡住

AI 拖拽或按住某键时如果被急停 / 插件进程退出，已经按下的按钮会被**自动释放**。面板上还有「释放全部按键/按钮」手动兜底。

> 为什么专门做这个：如果鼠标停在"按下"状态，你接下来的**每一次正常点击都会变成拖拽或多选** —— 这个现象很难联想到是插件造成的。

## 怎么用

1. 装好插件（它会随工作区绑定自动启动后台进程）
2. 在 AI 会话里直接说需求，例如「帮我在记事本里输入一段测试文字」
3. AI 首次调用时会**弹一次确认框**（claude 自带的工具权限框）—— 同意后本工作区不再重复询问
4. 想中途停下：按住 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>F12</kbd>

> AI 的工具表在**会话加载时**刷新 —— 刚装完插件要**重开会话**，AI 才看得到这个工具。

## 设置

| 项 | 默认 | 说明 |
|---|---|---|
| 急停快捷键 | `ctrl+alt+shift+f12` | 改成一个你不会误触的组合 |
| 禁止 AI 操作本应用窗口 | 开 | 见上方「安全设计 · 二」 |
| 拖拽默认时长 | 400ms | 越慢越稳（有些应用跟不上瞬移） |
| 输入字符间隔 | 4ms | 设 0 会让部分应用丢字 |

## 已知限制

- **管理员窗口点不动**：Windows 的安全限制（UIPI）—— 权限比本应用高的窗口（以管理员身份运行的程序、UAC 弹窗）收不到模拟输入。工具会检测并告诉你（"疑似被系统拦截"），而不是假装成功。
- **UAC 弹窗 / 锁屏界面**下完全无效（那是安全桌面，任何自动化都进不去）。
- **高 DPI 缩放**：已做 DPI 感知处理，但如果你在 125%/150% 缩放下发现点偏，面板里的实时坐标可以帮你确认。
- **中文输入**：走 Unicode 直发绕过输入法。若你的输入法处于拼音组合状态，可能吞掉首字 —— 输入前先按一次 Esc 更稳。
- **emoji / 生僻汉字**（非基本平面字符）：按 UTF-16 代理对发送，目标程序若不支持则显示异常。
- 仅 Windows。

## 依赖说明

插件自带两个开源库的**预编译二进制**（放在 `vendor/win32-x64/`），**不需要你安装任何东西、不需要编译工具链**：

- [robotjs](https://github.com/octalmage/robotjs)（MIT）—— 鼠标移动、点击、键盘输入
- [koffi](https://koffi.dev)（MIT）—— 调用 Windows API（急停检测、DPI、前台窗口判断、滚轮）

版权声明见 `vendor/*-LICENSE`。
