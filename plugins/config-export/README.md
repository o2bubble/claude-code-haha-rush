# 配置与资料导出

把本机上**已经调教好的一切**打包带走 —— 换电脑时不用从头再来。

## 它导出什么

| 分组 | 内容 |
|---|---|
| **Claude 个人资料** | `CLAUDE.md` 等个人指令、技能、记忆（每项目一份）、笔记、计划、会话历史 |
| **GUI 配置** | 全局设置、插件设置、超级桌面画布（`data.db`）|
| **工作区** | 每个工作区的 `settings.local.json` 与数据库 |

面板里按类勾选，每类显示**文件数 + 体积**。默认全选，但**会话历史默认不勾**
（可能有几百 MB，且是全部对话明文）。

## 它**绝不**导出什么

这些是硬编码的黑名单，即使你勾了相关分类也不会进包：

- `~/.claude/.credentials.json` —— 登录态
- `~/.claude/plugin-signing.key` —— 插件发布签名私钥
- `~/.claude/.env.active` / `.env.profiles` —— 可能含 API key

另外 **`settings.json` 的 `env` 段永远被剥离** —— 换机本来就要重配 key，
而泄露代价极高。剥离记录会写进包的 `manifest.json`，你能看出来少了什么。

> ⚠️ 压缩包**不加密**。勾选会话历史等敏感类时会有二次确认，请自行确认存放位置安全。

## 怎么用

1. 打开「配置导出」面板
2. 勾选要带走的内容（默认已选好）
3. 点「导出」→ 选保存位置
4. 拷到新电脑

## 包里有什么

```
claude-profile-export-20261025-1930.tar.gz
├── manifest.json     # 每个文件的来源、大小、hash、建议的恢复方式
└── data/
    ├── claude/settings.json
    ├── claude/skills/...
    ├── claude/projects/<slug>/memory/...
    └── workspaces/<slug>/data.db
```

`manifest.json` 里 `restore.mode` 标明每个文件该怎么恢复：
`overwrite`（整体替换）/ `merge`（合并）/ `append`（追加）/
**`manual`**（需人或 AI 判断 —— 记忆冲突、桌面数据库属于这类）。

## 自定义项 —— 你自己的备份方案

如果你已经有一套自己的迁移方案（手册 + 脚本 + 私有数据），在面板底部
「+ 添加目录」把它加进来。

**默认只记录说明，不打包数据** —— 因为：

- 你的方案通常已经把数据备份到它自己的地方（移动硬盘、云盘…）
- 我们再打一份是重复劳动
- 更重要：**不能违反你文档里定的规则**（哪些该带、哪些排除、什么顺序）

所以包内只会留一份说明（叫什么、入口文档是哪个、怎么导入、怎么验证）。
换机器时，AI 会读你的文档、按你的规则执行。

> 只有当你的方案**没有覆盖某些数据**、不带就会丢时，才勾「把数据也打进包」。

导出完成后，面板会**提醒你去跑自己的备份** —— 那一步我们不代劳。

## 已装插件怎么办

**插件源码与 runtime 不进包**（属可安装内容，市场可重装）。
但 `manifest.json` 的 `installedPlugins` 记录了**装了什么、什么版本、是否启用**，
恢复时可以据此重装。

## 依赖

- 需要 **nodejs** 插件（本插件进程用 node 运行）
- Windows 10+（用系统自带 `tar` 打包）
