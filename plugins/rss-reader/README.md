# RSS 订阅 (rss-reader)

订阅 RSS / Atom 源，集中查看。**新条目有未读标记 + 桌面挂件提醒** —— 适合盯各家
模型 API 的状态页：API 出问题时第一时间知道，不用自己疑惑。

## 做什么

| 能力 | 说明 |
|---|---|
| **订阅任意 RSS / Atom** | 粘贴链接即可。自动识别格式（两种都吃），自动取源标题作为订阅名 |
| **条目列表** | 按时间倒序，中英标题 / 摘要 / 相对时间；点开看详情 |
| **内嵌详情** | 正文在沙箱 iframe 里渲染（外部 HTML 隔离，源站内容带脚本也执行不了），支持「在浏览器打开原文」 |
| **未读标记** | 未读条目有蓝点；点开即已读；可一键「全部已读」（当前筛选范围） |
| **桌面挂件** | 一个常驻小窗显示未读数与最新标题。**有新条目时闪一下**，不用盯着面板 |
| **定时刷新** | 默认 10 分钟（可选 5/10/30/60），也可随时手动刷新 |

## 怎么用

1. **加源**：打开「RSS 订阅」面板 → 左下角输入框粘贴链接 → 添加。
   例如 DeepSeek 的状态页：
   ```
   https://status.deepseek.com/feed.rss
   ```
   添加时会先抓一次验证 —— 抓不通会明确告诉你原因，不会留下一个坏订阅。

2. **看内容**：条目按时间倒序排。点一条打开详情（正文 + 原文链接），点「← 返回」回列表。

3. **桌面挂件**：面板右下角点「桌面挂件」。挂件会出现在屏幕角落（默认右下），
   显示「N 条未读 + 最新一条标题」；新条目到达时窗口闪一下。
   挂件右上角 `✕` 关闭；也可以从命令面板执行「RSS：显示/收起桌面挂件」。

4. **快捷键**：命令面板（F1）里有两条命令，可在 设置 → 快捷键 里绑定：
   - `RSS：刷新全部订阅`
   - `RSS：显示/收起桌面挂件`

## 数据存哪

`%APPDATA%/com.claudecode.gui/plugins-data/rss-reader/`（Windows）——
`config.json` 存订阅列表与刷新间隔，`state.json` 存已读状态与抓取缓存。
**只存本地，不发给任何服务器**。卸载插件时宿主会自动清掉这个目录。

## 安全

- **抓取在插件进程里做**（node），不在面板 iframe 里 —— 一是绕开 CORS（源站不会给
  跨域头），二是实测有些站点的 TLS 配置本机 curl / Python 连不上、而 node 的 TLS
  栈能连上。
- 订阅链接**只允许 http/https**（`file:` / `javascript:` 等一律拒绝）。
- 详情正文在 `sandbox=""`（最严档）的 iframe 里渲染，外部 HTML 碰不到应用本身。
- 插件进程只绑 `127.0.0.1`，不监听局域网。

## 卸载

市场面板卸载即可。插件数据目录随卸载自动清理（宿主的卸载流程会清
`plugins-data/rss-reader/`），无需手动操作。
