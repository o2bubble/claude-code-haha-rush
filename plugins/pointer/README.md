# 屏幕指示器（教鞭）(pointer)

给 AI 一根**教鞭** —— 它可以在屏幕上画箭头、方框、圆圈、文字，**直接指给你「点这里」**。

## 它解决什么

以前 AI 说「你点右上角那个齿轮按钮」，你得自己找。现在它可以直接**圈出来给你看**。

配合另外两个能力，形成完整闭环：

```
你问「XX 在哪」
  → AI 查 功能手册（gui-manual）知道功能在哪
  → AI 用 截图工具 看一眼当前界面、定位到具体坐标
  → AI 用 本插件 在屏幕上画箭头/框指给你看
```

## 特点

- **不挡操作**：覆盖层是**点击穿透**的 —— 指示器画在屏幕上，但你点它下面的按钮照样点得到
- **自动消失**：默认 8 秒后淡出（可让 AI 设更久，或设 0 让它留着等你操作完）
- **压暗背景**：默认把屏幕压暗、**只把指的地方留亮**，视线自然被引过去
- **多目标**：一次可以画多个（比如带 ①②③ 编号的分步指引）

## 怎么用

**不需要你操作** —— 你在对话里问「XX 在哪」「怎么弄」时，AI 判断需要指给你看就会自动画。

如果想主动要：直接说「**圈给我看**」「**指一下**」「**在屏幕上标出来**」。

想提前关掉：说「**清掉指示器**」；或等它自己消失（默认 8 秒）。

## 支持哪些指示

| 形状 | 用途 |
|---|---|
| 箭头 | 从空白处指向目标（最常用） |
| 方框 | 框住一个按钮 / 输入框 / 区域 |
| 圆圈 | 圈住一个小图标 |
| 文字标签 | 「先点这里」这类说明；配在框/圈上的角标可当步骤号 |

## 已知边界

- **需要屏幕权限的概念**：它画在你**实际屏幕**上（不只是 GUI 窗口内）—— 所以你最小化 GUI 去看别的应用时，指示器也能指那边（只要那还在屏幕上）
- 覆盖层是**铺满一块显示器**的：多屏时指示器画在 AI 指定的那块屏幕上
- 需要宿主 GUI ≥ `2026.09.18.2`（透明 + 点击穿透的覆盖层是该版本新增的宿主能力）
