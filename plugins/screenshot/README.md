# 截屏 (screenshot)

截屏工具：三种模式、可设快捷键（**窗口不在前台也能按**），截完直接送去该去的地方。

## 做什么

| 能力 | 说明 |
|---|---|
| **全屏** | 抓光标所在的那块显示器 |
| **区域** | 冻结当前画面 → 拖框选择（见下方说明） |
| **窗口** | macOS 走系统原生点选；Windows 目前请用「区域」框住目标窗口 |
| **快捷键** | 默认 `Ctrl/Cmd + Shift + X` 触发区域截图（**全局热键**，别的应用在前台也生效）。可在 设置 → 快捷键 里改，五条命令都可绑 |
| **三个去向** | 插入聊天输入框（`@ref` 引用，点开可预览）/ 发送到超级桌面 / 仅保存到文件 |

默认保存位置是**当前工作区**的 `.claude/screenshots/`（跟粘贴图片的 `.claude/pasted/` 同一惯例，不污染工作区文件树）。可在 设置 → 插件 → 截屏 里改成固定目录。

## 怎么用

1. 装好后按 `Ctrl+Shift+X` → 屏幕变暗、出现选框 → 拖出要截的区域
2. 松手即自动投递（默认送到聊天输入框），并提示已保存
3. 想换去向：桌面面板里改「默认去向」，或事后在截屏面板里点缩略图重投

**框选时的按键**：`Esc` 取消 · `Enter` 用整屏 · 右键取消

## 区域截图为什么是"冻结"的

点区域截图时，程序会**先把屏幕抓成一张图**，再把这张图铺满屏幕让你框选，最后从这张图上裁。

这么做有两个好处：
- **所见即所截** —— 框选期间屏幕再变（弹窗、视频、切窗口）也不影响结果
- **不需要透明窗口** —— 显示的是不透明位图，避开了透明 + 置顶 + 点击穿透那一堆坑

## 依赖

- **node**（后台进程用）—— 若市场里装了 `nodejs` 插件会用它提供的运行时，否则用系统 node
- 抓屏走**系统自带能力**（Windows 用 PowerShell + .NET / macOS 用 `screencapture`），不下载任何额外二进制

## 权限

- **macOS**：首次使用会弹「屏幕录制」授权。**必须允许**，否则截出来是空白的桌面壁纸。
  若误点了拒绝：系统设置 → 隐私与安全性 → 屏幕录制 → 勾选本应用。
- **Windows**：无需额外授权。

## 快捷键冲突

`Ctrl+Shift+X` 若被别的软件占了（微信/QQ/截图工具），设置 → 快捷键 里那一行会标红「注册失败」——
换个键即可。全局热键是从所有应用手里抢键的，冲突是正常现象，不是坏了。

## 已知限制

- **Windows 的窗口模式**暂未实现（需要窗口枚举 + 悬停高亮）。macOS 有，走系统原生的点选。
- **跨显示器框选**：一次只能框一块显示器里的区域（框选窗口只覆盖光标所在那块）。想截另一块屏，把光标移过去再按快捷键。
