1. 启动、工作区与窗口

1.1 首次启动向导

  • 是什么：第一次打开 GUI 时的分步设置向导，依次问语言 → 界面字号 → 模型配置（Profile）→ 强制中文思考 → 面板布局介绍 → 服务区域（内网/公网服务器）。
  • 怎么用：首次启动自动弹出，按「下一步」逐步走完；最后一步可勾选「自动进入最近的工作区」。之后不会再出现，设置项随时可在「设置」里改。
  • 来源：gui/src/components/chat/WelcomeWizard.tsx

1.2 选择 / 切换工作区

  • 是什么：工作区 = 一个项目目录（Claude Code 的工作路径）。每个工作区有独立的后端进程、会话库、布局与桌面数据。
  • 怎么用：
    • 启动时若未开启「自动进入最近工作区」，会先出全屏选择页：点卡片选中 → 点「启动工作区」或双击卡片直接进入；「新建工作区」输入路径或点「浏览」；卡片右上角有删除按钮；顶部有搜索框。
    • 已进入后想换：点工具栏最左侧的工作区按钮（文件夹图标 + 当前目录名），会重新打开选择页。
    • 设置里有「自动进入最近的工作区」开关，开启后启动跳过选择页。
  • 来源：gui/src/components/chat/WorkspaceSelector.tsx、gui/src/components/Toolbar.tsx

1.3 打开新 GUI 实例（新窗口）

  • 是什么：再启动一个完整的 GUI 窗口（可同时开多个工作区），新窗口是独立实例。
  • 怎么用：点工具栏上的「新实例」（带文字标签的那个按钮）；窗口较窄时它也不会被折叠。
  • 来源：gui/src/components/Toolbar.tsx（spawnNewInstance，Rust spawn_gui_instance）

1.4 窗口控制（Windows 自绘标题栏）

  • 是什么：Windows 上标题栏是自绘的，与工具栏合并成一条 36px 的横条；右上角是 最小化 / 最大化(还原) / 关闭 三个按钮。macOS 保留系统原生标题栏。
  • 怎么用：拖动标题栏空白处移动窗口；双击标题栏空白处最大化/还原（框架内置）；边缘可拖拽缩放。工作区选择页与欢迎向导这类全屏覆盖层也各自在右上角挂了窗口按钮。
  • 来源：gui/src/components/TitleBar.tsx、gui/src/components/Toolbar.tsx；实现说明见 window-chrome.md

1.5 主题、语言、界面字号

  • 是什么：整套界面配色（浅色 / 深色 / 深蓝专业 / 高级深灰）、界面语言（中文 / English）、全局 UI 字体缩放（70%~150%）。
  • 怎么用：主题在 设置 → 基础 → 界面主题 选，或在应用菜单里点「切换到亮色/暗色主题」；语言在 设置 → 基础 → 语言；字号用 设置 → 基础 → 界面字体大小 拖动滑块（松开后生效）。
  • 来源：gui/src/components/chat/SettingsPanel.tsx、gui/src/components/Toolbar.tsx

2. 界面布局

2.1 四区布局与三侧栏开关

  • 是什么：左侧边栏（导航面板）+ 中央（编辑器 / 超级桌面）+ 右侧聊天（消息 + 输入）+ 底部（终端）。
  • 怎么用：工具栏最左边三个按钮分别切换 左侧栏 / 右侧聊天区 / 底部终端 的显示隐藏。
  • 来源：gui/src/components/Toolbar.tsx

2.2 面板开关（面板下拉）

  • 是什么：列出所有可由用户管理（userManaged）的面板，点一下开、再点一下关；已打开的面板排在前面并带 ✓。
  • 怎么用：点工具栏「面板」下拉（图标 + 已开数量），点任意面板名切换。也可在命令面板（F1）里搜面板名。
  • 来源：gui/src/components/Toolbar.tsx（PanelDropdown）、gui/src/services/panelDefs.tsx

2.3 拖动分割线调整大小

  • 是什么：不需要进任何模式，直接拖动面板之间的分割线即可调整左/右/底部面板的宽高。
  • 怎么用：把鼠标移到两个面板之间的边界上，光标变成拖拽形态时按住拖动。
  • 来源：gui/src/components/LayoutRenderer.tsx

2.4 布局预设

  • 是什么：一键切换整套排布的三套预设：默认布局 / 以聊天为主 / 信息密度最高（附迷你示意图）。
  • 怎么用：点工具栏「布局预设」按钮 → 点一张预览卡 → 确认框里点「应用」。会覆盖当前布局（含浮动窗口），不可撤销。
  • 来源：gui/src/components/Toolbar.tsx（LayoutPresetDropdown）、gui/src/stores/layoutStore.ts（LAYOUT_PRESETS）

2.5 布局编辑模式

  • 是什么：进入后每个面板顶部出现操作手柄，可自由拖拽、分割、浮动、换图标；顶部有绿色横幅提示，右下角是「完成布局」。
  • 怎么用：点工具栏「布局编辑模式」按钮（或在应用菜单里点）。每个面板顶部出现一排小按钮（顶部横幅把它们写作 ≡ ⇄ ⧉）：
    • 拖动把手 ≡：按住拖动换位置（拖到别的面板边缘 = 分割落位）
    • 分割 ⇄：点开选 向左/向右/向上/向下分割
    • 浮动 ⧉：浮动为窗口
    • ✕：关闭（固定分组上是「隐藏」）
    • ⋯ 更多：其余操作（含「更换图标」等标签页菜单项）
    • 按 Esc 或点右下角「完成布局」退出，退出后保持你的排布。
  • 来源：gui/src/components/LayoutRenderer.tsx、gui/src/stores/layoutMode.ts

2.6 标签页右键菜单与拖拽

  • 是什么：每个面板标签支持右键菜单和在分组间拖拽合并/移动。
  • 怎么用：
    • 右键面板标签（布局层）：浮动标签 / 在新窗口打开 / 关闭标签；如果它是「分组」标签（一个标签里叠了多个面板），菜单里另有 解散分组 / 更换图标。编辑器标签另有一套菜单（关闭其他/关闭未修改的/关闭全部/复制路径…），见 5.5。
    • 直接拖动标签到另一个面板的标签栏上即可合并成一组；拖到空分组的提示区（「拖拽标签页到此处」）可放入。
    • 标签过多时右侧出现「更多面板」溢出按钮。
  • 来源：gui/src/components/LayoutRenderer.tsx

2.7 浮动窗口（面板浮出 / 停靠回主窗口）

  • 是什么：可以把任意面板浮成主窗口内的浮动卡片（可拖动、可调大小、可置顶），或进一步成为独立的系统窗口；独立窗口可拖回主窗口停靠。
  • 怎么用：
    • 浮动卡片：标签右键 →「浮动标签」，或布局模式里点 ⧉。
    • 独立窗口：标签右键 →「在新窗口打开」，或浮动卡片标题栏上的「在新窗口打开」。
    • 停靠回来：把独立窗口拖到主窗口上（提示「拖入主窗口」）→ 松手停靠。
    • 关闭：卡片右上角 ×。
  • 来源：gui/src/components/FloatingRenderer.tsx、gui/src/FloatingApp.tsx、gui/src/stores/layoutStore.ts

2.8 布局持久化

  • 是什么：布局按工作区自动保存，下次进入该工作区自动恢复（含浮动窗口）。设置里另有开关可把布局同时写入全局，作为新工作区的默认。
  • 怎么用：不用操作，改动即保存；需要「新工作区也套用这套布局」时，去 设置 → 基础 → 打开「保存布局到全局」。
  • 来源：gui/src/stores/layoutStore.ts、gui/src/components/chat/SettingsPanel.tsx

2.9 面板清单（24 个）

  • 是什么：GUI 注册的全部面板。14 个是用户管理面板（会持久化，可在「面板」下拉里开关，也能进命令面板搜索），10 个是系统面板（只在相关时机出现、不持久化）。
  • 怎么用：用户管理面板 —— 编辑器、工作进程、计划、子代理、消息、输入、技能、会话、文件、笔记、终端、超级桌面、快捷提示、插件市场。 系统面板 —— 设置、技能详情（skill-dialog）、插件详情、提问、桌面项目、Profile 管理、反馈、更新、帮助、运行环境诊断。
  • 来源：gui/src/services/panelDefs.tsx（ALL_PANEL_DEFS）

3. 聊天与对话

3.1 发送消息

  • 是什么：底部输入框发消息给 AI；AI 正在思考时按钮变成「停止」。
  • 怎么用：默认 Enter 发送、Shift+Enter 换行；可在 设置 → 聊天 → Enter 键 改成「Enter 换行、Ctrl+Enter 发送」。输入框内左下角会实时显示当前键位提示。AI 思考中时发送按钮变「停止」，点它中断本次生成。
  • 来源：gui/src/components/chat/InputArea.tsx、gui/src/components/chat/SettingsPanel.tsx

3.2 引用芯片（@ref）：把文件 / 长文本 / 图片"塞"给 AI

  • 是什么：粘贴或发送的内容会自动变成带图标的引用芯片（如 📄 main.ts），鼠标点芯片可删除；AI 能直接读到被引用的原始资源。
  • 怎么用：在输入框 Ctrl+V，粘贴内容会被自动判定——
    • 剪贴板里是文件 / 文件夹（在资源管理器里 Ctrl+C，过来粘贴）→ 文件引用 / 文件夹引用芯片；
    • 是图片或剪贴板里的文件对象 → 先存到工作区，再变成文件引用芯片；
    • 是文本、且内容正好是一个真实存在的路径 → 变成对应文件/文件夹的引用芯片；
    • 是长文本（超过 120 字符）→ 变成 paste 引用芯片（AI 仍能拿到全文）；
    • 是短文本 → 按普通文本插入光标处。
    • 从各处菜单「发送到聊天」也会插入芯片（见 3.3）；芯片点一下即可删除，也可在输入框里直接手写 @ref{file:...}，发送时自动转成芯片。
  • 来源：gui/src/components/chat/InputArea.tsx、gui/src/services/clipboardService.ts、gui/src/utils/referenceParser.ts；语法见 ref-system.md

3.3 从各处「发送到聊天」

  • 是什么：多个面板都能把内容作为引用塞进聊天输入框，省去手打路径。
  • 怎么用：
    • 文件树：右键文件 →「发送到聊天」，或按 Ctrl+C（复制文件路径，文件面板内生效）。
    • 编辑器：右键 →「发送到聊天」（带当前行号/选区行范围）。
    • 消息：选中文字 → 划词工具栏 →「发送到聊天框」；消息底部也有复制/发送到桌面。
    • 笔记：笔记上右键 →「发送到聊天」。
    • 超级桌面：项目右键 →「发送给 Agent」（可多选批量发送）。
    • 消息里的内联引用链接（@ref{...} 芯片）点击可直接打开对应资源。
      • ⚠️ 其中 @ref{panel:xxx} 只有该面板已经打开时才会切过去；没打开会提示 Panel "xxx" not found —— 想让 AI 用引用指向某个面板，先自己把那个面板打开。
    • @ref{dir:...} 目前只弹一条状态消息提示路径，不会在文件树里定位（尚未实现）。
  • 来源：gui/src/components/FileTree.tsx、gui/src/components/Editor.tsx、gui/src/components/chat/NotesPanel.tsx、gui/src/components/desktop/SuperDesktopCanvas.tsx

3.4 斜杠命令

  • 是什么：输入 / 弹出命令下拉（AI 命令 + 技能），键盘上下选、Enter 确认；部分命令在 GUI 里有特殊去处。
  • 怎么用：在输入框敲 /，下拉里继续输入可过滤；↑/↓ 选择、Enter 或点击插入、Esc 关闭。发送后 GUI 会自动分流：
    • /plan、/desktop、/diff（→ 编辑器）等 → 直接打开对应面板，不发给后端；/tasks、/model 也走这条路由，但目标面板当前不存在，会提示「面板 xxx 未打开，请使用面板菜单添加」；
    • /config、/memory、/doctor、/plugins、/hooks 等 → 打开系统终端执行（Windows 优先 Git Bash，缺失时用命令提示符并提示）；
    • /exit、/login、/logout、/upgrade 等在 GUI 里不可用，会提示「此命令在 GUI 中不可用」；
    • 其余按普通消息发给 AI。
  • 来源：gui/src/components/chat/SlashCommandDropdown.tsx、gui/src/utils/commandRouter.ts、gui/src/components/chat/ChatInputPanel.tsx

3.5 消息队列

  • 是什么：AI 忙的时候（思考/执行中）发送的消息不会丢，进入队列，等这一回合结束后自动逐条发出；队列可暂停、编辑、调序、立即插队。
  • 怎么用：正常发送即可入队。队列条显示「N 条排队中」，按钮有：
    • 「自动 / 暂停」切换自动发送；
    • 每条右侧：⚡ 立即发送（提到队首）、↑↓ 上下移、✎ 编辑（弹窗改文字）、✕ 移除；
    • 表头：🗑 全部清空、切换「输入框上方 / 聊天右侧」位置、展开/收起。
    • 位置与上限在 设置 → 聊天 →「消息队列位置 / 消息队列上限」（默认 20 条）。
  • 来源：gui/src/components/chat/MsgQueuePanel.tsx、gui/src/stores/msgQueueStore.ts

3.6 权限确认弹窗

  • 是什么：AI 要执行敏感操作（改文件、跑命令）时弹出确认，可选「拒绝 / 始终允许 / 允许」。
  • 怎么用：弹窗出现在输入面板上方，点按钮即可；「始终允许」表示本会话内同类操作不再追问。整体授权级别用工具栏的权限模式下拉调整：默认 / 接受编辑 / 计划模式 / 绕过 / 不再询问。
  • 来源：gui/src/components/chat/ChatInputPanel.tsx、gui/src/components/Toolbar.tsx（PermModeDropdown）

3.7 AI 提问面板（AskUserQuestion）

  • 是什么：AI 反过来问你问题时，会浮出一个提问面板：选项按钮（可多选）+ 可选备注（annotations）。
  • 怎么用：AI 提问时自动浮出（浮动窗），选好选项后可填备注，点「提交」；或点「跳过」让 AI 自己决定。
  • 来源：gui/src/components/chat/AskQuestionOverlay.tsx、gui/src/components/chat/AskQuestionFloating.tsx

3.8 状态条、上下文进度与压缩

  • 是什么：输入框下方一条状态栏：连接状态圆点（已连接/思考中/未连接）、无响应秒数、ctx 已用/窗口 token 数、上下文占用进度条与百分比、「压缩」按钮。
  • 怎么用：
    • 鼠标悬停 token 数字看明细（input/output/cache read/cache create）。
    • 点「压缩」按钮压缩当前会话上下文。
    • 上下文占用超过阈值（默认 90%）会弹浮动告警，可点「去设置」直达阈值配置，或 ✕ 关掉。
    • 阈值与开关在 设置 → 聊天 →「上下文告警 / 告警阈值 (%)」。
  • 来源：gui/src/components/chat/ChatInputPanel.tsx（ChatStatusBar）、gui/src/utils/contextWarning.ts

3.9 流卡死决策条

  • 是什么：模型流长时间无响应时（默认 30s 起提示），除了状态栏显示「已 N 秒无响应」，还会弹出一条决策条，让你裁量而不是干等。

3.10 消息操作

  • 是什么：每条 AI 消息下/工具栏上的操作，以及工具调用卡片的展开折叠。

    • 长文本消息有「▼ 显示全部（N 字符）/ ▲ 收起」。

3.11 搜索消息 / 只看我的消息

3.13 消息划词工具栏

6. 超级桌面（无限画布）

    • 工具栏右端的搜索框按标签或内容过滤，不匹配的块会变暗（✕ 清空搜索）；

6.3 内容块（用户可创建 5 种 + 拖入 3 种 + AI 1 种）

  • 是什么：画布上的卡片。用户在工具栏可直接新建：文本（+ 文本）/ 表格（+ 表格）/ 表单（+ 表单）/ 绘图（+ 绘图）/ 图形（+ 图形，输入 Mermaid）；拖入或粘贴文件得到 图片 / 文件组 / @引用；图表目前只能由 AI 创建（工具栏无图表按钮）。
  • 怎么用：
    • 点工具栏对应按钮，新块落在视口中央；空白处右键也能新建（文本/表单/绘图）或「重置视图」。
    • 文本块：双击编辑，右上角「格式」下拉可切 纯文本 / Markdown / 代码语言。
    • 表格块：点单元格直接编辑，+ 行 加行、表头 + 加列、双击列名改名、列头 ✕ 删列。
    • 表单块：+ 添加字段 选类型（文本/多行文本/数字/复选框/下拉/日期/开关/单选/颜色/滑块），⚙ 配置（必填、最大长度、行数、min/max/step、选项），字段可拖拽排序、双击改名、× 删除；填完值可「发送给 Agent」。
    • 绘图块：工具 画笔/矩形/圆/直线/箭头/文字/橡皮，调颜色、线宽、填充、透明度，↩↪ 撤销重做，✕ 清空，「完成」退出编辑。
    • 图形块：双击可打开 Mermaid 编辑弹窗（粘贴/编辑 Mermaid 代码，预览后保存）。

8.1 技能面板

  • 是什么：AI 的「专项能力包」管理：本地已安装 + 在线技能库两个标签页。
  • 怎么用：切换「已安装 / 在线库」；搜索框过滤；在线库条目点「安装」（或「安装全部」）；已安装条目可删除；技能条目点开详情弹窗（可收藏 ☆、填参数后发送，Enter 换行 / Shift+Enter 发送）。
    • 装好后技能会出现在 AI 可调用的工具/命令列表中（会话启动时扫描，新装技能需新开会话才生效）。
  • 来源：gui/src/components/chat/SkillsPanel.tsx、SkillDialog.tsx、gui/src/services/skillMarketplace.ts

8.2 技能描述翻译

  • 是什么：把技能描述翻译成中文（通过 CLI 调用模型，约 1–2 分钟）。
  • 怎么用：面板头部的「翻译 / 重新翻译」按钮，翻译结果缓存复用；未翻译的条目显示「(未翻译)」。
  • 来源：gui/src/components/chat/SkillsPanel.tsx

8.3 插件市场

  • 是什么：浏览、安装、更新、卸载 GUI 插件（插件可带来新面板、命令、快捷键、后台进程甚至桌面控制能力）。
  • 怎么用：
    • 左侧列表（可搜、按分类筛：全部/组件/工具/指导/集成），右侧详情（README、作者、版本、下载量、依赖）。
    • 卡片按钮按状态变化：安装 / 更新（有新版时带「可更新」角标）/ 卸载 / 禁用 / 启用。
    • 卸载有二次确认，会删除插件文件并移除其面板与命令；若插件声明「卸载后需重启」，会问你是否现在重启；清理没跑完会如实告知。
    • 缺依赖时安装会问「是否一并安装依赖」；依赖已装但环境未就绪也如实提示。
    • 未签名插件（「未受信任」）与不支持当前平台的插件都有角标提示；未受信任插件只能走「AI 安装」。
    • 「AI 安装 / AI 卸载」：把安装/卸载任务交给 AI 执行（需要在聊天里有可用会话）。
  • 来源：gui/src/components/chat/PluginMarketPanel.tsx、PluginMarketDetailPanel.tsx、gui/src/services/pluginRegistry.ts

8.4 插件设置

  • 是什么：插件自己声明的设置项，集中显示在 设置 → 插件；没有设置项的插件不出现。
  • 怎么用：设置 → 插件 → 选择「保存范围（全局 / 工作区）」，改完即存。
  • 来源：gui/src/components/chat/SettingsPanel.tsx（PluginSettingsPanel）、gui/src/services/pluginSettingsStore.ts

8.5 插件带来的能力（取决于装了哪个插件）

  • 是什么：插件可往 GUI 里加面板、命令（进命令面板，可带快捷键）、后台进程（工作进程面板可见）、覆盖层与置顶小浮标；有些插件还会贡献技能、或给 AI 提供新工具（如浏览器自动化、截屏、鼠标键盘控制、只读 git 查看）。
  • 怎么用：装完插件后，其面板出现在**「面板」下拉里、也能在命令面板（F1）**里搜到，命令同样出现在命令面板；是否需要重启、是否缺少运行环境，插件市场与 AI 都会明确告诉你。判断某个能力能不能用，先看「工作进程」面板与命令面板里有没有它。
  • 来源：gui/src/services/pluginRegistry.ts、pluginPanelBridge.tsx、pluginCommandBridge.ts、pluginProcessBridge.ts；插件进程的宿主窗口见 gui/src-tauri/src/lib.rs（open_plugin_overlay / open_plugin_indicator）

11. 模型、Profile 与权限

11.1 模型下拉（工具栏）

  • 怎么用：点工具栏的模型名按钮：

11.2 Profile 管理

14. 命令面板与帮助

15. 其他交互

15.1 外部链接怎么打开

  • 是什么：界面里的 http(s) 链接有统一的打开策略（防止把 GUI 页面本身导航走）。
  • 怎么用：左键 = 在应用内置的原生窗口里打开；Ctrl/⌘ + 左键或鼠标中键 = 用系统默认浏览器打开；右键 = 菜单（内置窗口打开 / 在系统浏览器打开 / 复制链接）。

15.2 通知与消息记录

  • 是什么：操作结果以右下角 Toast（成功 3s 自动消失、警告 6s、错误常驻可关）告知；同时所有消息被记录，左下角的胶囊（圆点 + 条数）在 5 秒内自动展开显示最新一条（悬停暂停收回），点它打开完整「消息记录」列表（倒序，可「清空」）。
  • 怎么用：不用刻意操作；出错时看右下角或左下角。
  • 来源：gui/src/components/ToastContainer.tsx、gui/src/components/StatusBar.tsx

15.3 无人值守守护模式

  • 是什么：实验性「撒手模式」：每个回合结束后自动验收任务，未完成自动续做，队列任务仅在验收通过后放行，全部完成自动退出。
  • 怎么用：点工具栏的盾牌按钮 → 阅读风险清单（模型自评不可靠 / 无轮数上限持续耗 token / 非 bypass 权限下会挂起 / 格式不合规会暂停 / AI 将自主连续执行多回合）→「进入无人值守(自担风险)」。运行中盾牌带状态色点（回合观察中 / 验收等待中 / 已暂停(异常)）；再点一次即停止。
  • 来源：gui/src/components/chat/GuardButton.tsx、gui/src/services/guardBridge.ts、gui/src-tauri/src/guard.rs
