# 4. 会话管理

### 4.1 新建 / 切换 / 重命名 / 删除

- **是什么**：会话面板保存所有历史对话；每工作区独立。
- **怎么用**（面板顶部一排按钮）：↻ 刷新、＋ 新建会话、☑ 选择（进入多选模式，可批量删除）。
  - 点任意会话切换；会话名右侧 ✎ 就地重命名。
  - 悬停会话行右侧出现 ☆ 收藏、⋯ 更多操作（复制名称 / 分叉会话 / 重命名 / 移动到文件夹 / 在新窗口打开 / 删除）。
  - 删除有二次确认；多选模式底部有「删除选中 (N)」。
- **来源**：`gui/src/components/chat/SessionPanel.tsx`

### 4.2 收藏

- **是什么**：把常用会话钉在列表顶部「收藏」分组，跨列表位置始终可见。
- **怎么用**：点会话行的 ☆ 收藏/取消；收藏区里若会话已不存在，显示「已失效（会话不存在）」并可移除。
- **来源**：`gui/src/components/chat/SessionPanel.tsx`（`sessionFavorites.ts`）

### 4.3 会话文件夹（需开启）

- **是什么**：按文件夹（支持嵌套树）组织会话，未归类的会话放在「未归类」。
- **怎么用**：先在 设置 → 会话 → 打开「会话文件夹」，面板里才会出现文件夹区：「新建文件夹」、文件夹行上的 ＋（新建子文件夹）/ 移动 / 重命名 / 删除；会话右键「移动到文件夹」（支持批量移动）。删除文件夹只把会话移出，不会删会话。
- **来源**：`gui/src/components/chat/SessionPanel.tsx`（`sessionFolders.ts`）

### 4.4 分叉会话

- **是什么**：从当前会话复制出一条新会话（保留已有对话），用于「从这里换个方向继续试」。
- **怎么用**：会话行 ⋯ 菜单 →「分叉会话」，成功后提示「已创建分叉会话」。
- **来源**：`gui/src/components/chat/SessionPanel.tsx`

### 4.5 在新窗口打开

- **是什么**：把某个会话丢到另一个 GUI 窗口中打开（新实例/已有实例），方便并排对比两条线。
- **怎么用**：会话行 ⋯ 菜单 →「在新窗口打开」。若该会话正被另一实例使用，会先弹「会话已被另一窗口打开」确认。
- **来源**：`gui/src/components/chat/SessionPanel.tsx`

### 4.6 会话状态与打断保护

- **是什么**：当前会话行有状态标识：工作中 / 空闲；被其他窗口占用时显示「会话已被另一窗口打开」。
- **怎么用**：切到一个**正在工作**的会话时会弹「当前会话正在工作中」确认，说明切换会打断它，可选「仍要切换」。
- **来源**：`gui/src/components/chat/SessionPanel.tsx`（`sessionSwitchGuard.ts`、`stores/sessionStatusStore.ts`）
