# 1. 启动、工作区与窗口

### 1.1 首次启动向导

- **是什么**：第一次打开 GUI 时的分步设置向导，依次问语言 → 界面字号 → 模型配置（Profile）→ 强制中文思考 → 面板布局介绍 → 服务区域（内网/公网服务器）。
- **怎么用**：首次启动自动弹出，按「下一步」逐步走完；最后一步可勾选「自动进入最近的工作区」。之后不会再出现，设置项随时可在「设置」里改。
- **来源**：`gui/src/components/chat/WelcomeWizard.tsx`

### 1.2 选择 / 切换工作区

- **是什么**：工作区 = 一个项目目录（Claude Code 的工作路径）。每个工作区有独立的后端进程、会话库、布局与桌面数据。
- **怎么用**：
  - 启动时若未开启「自动进入最近工作区」，会先出全屏选择页：点卡片选中 → 点「启动工作区」或**双击卡片**直接进入；「新建工作区」输入路径或点「浏览」；卡片右上角有删除按钮；顶部有搜索框。
  - 已进入后想换：点工具栏最左侧的**工作区按钮**（文件夹图标 + 当前目录名），会重新打开选择页。
  - 设置里有「自动进入最近的工作区」开关，开启后启动跳过选择页。
- **来源**：`gui/src/components/chat/WorkspaceSelector.tsx`、`gui/src/components/Toolbar.tsx`

### 1.3 打开新 GUI 实例（新窗口）

- **是什么**：再启动一个完整的 GUI 窗口（可同时开多个工作区），新窗口是独立实例。
- **怎么用**：点工具栏上的「新实例」（带文字标签的那个按钮）；窗口较窄时它也不会被折叠。
- **来源**：`gui/src/components/Toolbar.tsx`（`spawnNewInstance`，Rust `spawn_gui_instance`）

### 1.4 窗口控制（Windows 自绘标题栏）

- **是什么**：Windows 上标题栏是自绘的，与工具栏合并成一条 36px 的横条；右上角是 最小化 / 最大化(还原) / 关闭 三个按钮。macOS 保留系统原生标题栏。
- **怎么用**：拖动标题栏空白处移动窗口；**双击标题栏空白处**最大化/还原（框架内置）；边缘可拖拽缩放。工作区选择页与欢迎向导这类全屏覆盖层也各自在右上角挂了窗口按钮。
- **来源**：`gui/src/components/TitleBar.tsx`、`gui/src/components/Toolbar.tsx`；实现说明见 [`window-chrome.md`](./window-chrome.md)

### 1.5 主题、语言、界面字号

- **是什么**：整套界面配色（浅色 / 深色 / 深蓝专业 / 高级深灰）、界面语言（中文 / English）、全局 UI 字体缩放（70%~150%）。
- **怎么用**：主题在 设置 → 基础 → 界面主题 选，或在应用菜单里点「切换到亮色/暗色主题」；语言在 设置 → 基础 → 语言；字号用 设置 → 基础 → 界面字体大小 拖动滑块（**松开后生效**）。
- **来源**：`gui/src/components/chat/SettingsPanel.tsx`、`gui/src/components/Toolbar.tsx`
