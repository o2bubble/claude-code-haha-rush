# 2. 界面布局

### 2.1 四区布局与三侧栏开关

- **是什么**：左侧边栏（导航面板）+ 中央（编辑器 / 超级桌面）+ 右侧聊天（消息 + 输入）+ 底部（终端）。
- **怎么用**：工具栏最左边三个按钮分别切换 **左侧栏 / 右侧聊天区 / 底部终端** 的显示隐藏。
- **来源**：`gui/src/components/Toolbar.tsx`

### 2.2 面板开关（面板下拉）

- **是什么**：列出所有可由用户管理（`userManaged`）的面板，点一下开、再点一下关；已打开的面板排在前面并带 ✓。
- **怎么用**：点工具栏「面板」下拉（图标 + 已开数量），点任意面板名切换。也可在命令面板（F1）里搜面板名。
- **来源**：`gui/src/components/Toolbar.tsx`（`PanelDropdown`）、`gui/src/services/panelDefs.tsx`

### 2.3 拖动分割线调整大小

- **是什么**：不需要进任何模式，直接拖动面板之间的分割线即可调整左/右/底部面板的宽高。
- **怎么用**：把鼠标移到两个面板之间的边界上，光标变成拖拽形态时按住拖动。
- **来源**：`gui/src/components/LayoutRenderer.tsx`

### 2.4 布局预设

- **是什么**：一键切换整套排布的三套预设：默认布局 / 以聊天为主 / 信息密度最高（附迷你示意图）。
- **怎么用**：点工具栏「布局预设」按钮 → 点一张预览卡 → 确认框里点「应用」。**会覆盖当前布局（含浮动窗口），不可撤销**。
- **来源**：`gui/src/components/Toolbar.tsx`（`LayoutPresetDropdown`）、`gui/src/stores/layoutStore.ts`（`LAYOUT_PRESETS`）

### 2.5 布局编辑模式

- **是什么**：进入后每个面板顶部出现操作手柄，可自由拖拽、分割、浮动、换图标；顶部有绿色横幅提示，右下角是「完成布局」。
- **怎么用**：点工具栏「布局编辑模式」按钮（或在应用菜单里点）。每个面板顶部出现一排小按钮（顶部横幅把它们写作 `≡` `⇄` `⧉`）：
  - 拖动把手 `≡`：按住拖动换位置（拖到别的面板边缘 = 分割落位）
  - 分割 `⇄`：点开选 向左/向右/向上/向下分割
  - 浮动 `⧉`：浮动为窗口
  - `✕`：关闭（固定分组上是「隐藏」）
  - `⋯` 更多：其余操作（含「更换图标」等标签页菜单项）
  - 按 `Esc` 或点右下角「完成布局」退出，退出后保持你的排布。
- **来源**：`gui/src/components/LayoutRenderer.tsx`、`gui/src/stores/layoutMode.ts`

### 2.6 标签页右键菜单与拖拽

- **是什么**：每个面板标签支持右键菜单和在分组间拖拽合并/移动。
- **怎么用**：
  - 右键面板标签（布局层）：浮动标签 / 在新窗口打开 / 关闭标签；如果它是「分组」标签（一个标签里叠了多个面板），菜单里另有 解散分组 / 更换图标。**编辑器标签**另有一套菜单（关闭其他/关闭未修改的/关闭全部/复制路径…），见 5.5。
  - 直接**拖动标签**到另一个面板的标签栏上即可合并成一组；拖到空分组的提示区（「拖拽标签页到此处」）可放入。
  - 标签过多时右侧出现「更多面板」溢出按钮。
- **来源**：`gui/src/components/LayoutRenderer.tsx`

### 2.7 浮动窗口（面板浮出 / 停靠回主窗口）

- **是什么**：可以把任意面板浮成主窗口内的浮动卡片（可拖动、可调大小、可置顶），或进一步成为独立的系统窗口；独立窗口可拖回主窗口停靠。
- **怎么用**：
  - 浮动卡片：标签右键 →「浮动标签」，或布局模式里点 `⧉`。
  - 独立窗口：标签右键 →「在新窗口打开」，或浮动卡片标题栏上的「在新窗口打开」。
  - 停靠回来：把独立窗口拖到主窗口上（提示「拖入主窗口」）→ 松手停靠。
  - 关闭：卡片右上角 ×。
- **来源**：`gui/src/components/FloatingRenderer.tsx`、`gui/src/FloatingApp.tsx`、`gui/src/stores/layoutStore.ts`

### 2.8 布局持久化

- **是什么**：布局按工作区自动保存，下次进入该工作区自动恢复（含浮动窗口）。设置里另有开关可把布局同时写入全局，作为新工作区的默认。
- **怎么用**：不用操作，改动即保存；需要「新工作区也套用这套布局」时，去 设置 → 基础 → 打开「保存布局到全局」。
- **来源**：`gui/src/stores/layoutStore.ts`、`gui/src/components/chat/SettingsPanel.tsx`

### 2.9 面板清单（24 个）

- **是什么**：GUI 注册的全部面板。14 个是**用户管理面板**（会持久化，可在「面板」下拉里开关，也能进命令面板搜索），10 个是**系统面板**（只在相关时机出现、不持久化）。
- **怎么用**：用户管理面板 —— 编辑器、工作进程、计划、子代理、消息、输入、技能、会话、文件、笔记、终端、超级桌面、快捷提示、插件市场。
  系统面板 —— 设置、技能详情（`skill-dialog`）、插件详情、提问、桌面项目、Profile 管理、反馈、更新、帮助、运行环境诊断。
- **来源**：`gui/src/services/panelDefs.tsx`（`ALL_PANEL_DEFS`）
