# 12. 设置与快捷键

### 12.1 设置面板

- **是什么**：所有可配置项的集中地，左侧分类导航、右侧表单、底部保存栏。
- **怎么用**：工具栏齿轮按钮打开（浮窗）。**底部「保存到：全局 / 当前工作区」决定写哪份配置**——多数字段改完要按「保存」；快捷键、服务器地址是改完即存。部分字段由命令面板/告警跳进来时会自动定位并高亮。
- **来源**：`gui/src/components/chat/SettingsPanel.tsx`

### 12.2 设置项一览

- **基础**：语言、界面主题、界面字体大小、自动进入最近的工作区、保存布局到全局、服务器地址（内网 96 / 公网云 / 自定义）。
- **文件管理**：显示隐藏文件、排序方式（名称/日期/类型）。
- **终端**：历史条目上限、终端字体大小。
- **编辑器**：字体大小、Tab 宽度、自动换行。
- **聊天**：Enter 键行为、自动加载最近会话、强制中文思考、消息队列位置与上限、消息划词工具栏、消息时间线、上下文告警（开关 + 阈值）、自定义压缩提示词（开关/追加或替换/预设/提取脚本）、唤醒提示词。
- **会话**：会话文件夹（开关）。
- **超级桌面**：暂无可配置项（代码里显示空态）。
- **快捷键**：见 12.3。
- **插件**：插件声明的设置项。
- **技能**：此分类当前为空。
- **关于**：版本号、技术栈、源码仓库链接（Gitee 主仓库 / GitHub 镜像，打不开时自动复制到剪贴板）。
- **来源**：`gui/src/components/chat/SettingsPanel.tsx`（`CATEGORIES` / `CategoryContent`）

### 12.3 快捷键设置

- **是什么**：改键界面，含冲突提示与「局部交互键」说明。
- **怎么用**：设置 → 快捷键 → 点某条键位 → 按下新组合（`Esc` 取消）；「恢复默认 / 全部恢复默认」；紫色虚线框的条目是**上下文条件型**（只在特定面板生效，不可修改）。
  - 冲突是**软冲突**：允许重复，但顶部提示「N 组键位冲突（按列表顺序，靠前者优先）」。
  - 插件声明的快捷键也出现在这里，带「（全局，窗口不在前台也生效）」角标的表示注册为 **OS 级全局热键**；被其它软件占用或已被另一个 GUI 实例占用时会给出对应提示与「重新检测」。
  - 完整键位表与规则见 [`shortcuts.md`](./shortcuts.md)。
- **来源**：`gui/src/components/chat/ShortcutsPanel.tsx`、`gui/src/services/shortcuts.ts`、`gui/src/services/globalShortcutService.ts`
