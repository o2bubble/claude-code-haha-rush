# 7. 笔记

### 7.1 浏览、搜索、筛选、排序

- **是什么**：个人知识库（Markdown），**跨工作区共享**（用户级）。
- **怎么用**：顶部「+ 新建笔记」；搜索框即时过滤；漏斗按钮打开筛选弹层（作用域 / 标签 / 排序：最近更新、标题 A-Z）；列表显示笔记数、更新时间（刚刚 / N 分钟前…）。
- **来源**：`gui/src/components/chat/NotesPanel.tsx`

### 7.2 编辑

- **是什么**：所见即所得编辑器（默认）与 Markdown 源码模式可切换，自动保存。
- **怎么用**：编辑标题、标签（`+ 标签` 回车添加，标签上 × 移除）、作用域（如 `global`、`domain:rust`）；工具栏按钮：粗体/斜体/删除线/内联代码、H1-H3、无序/有序列表、引用、代码块、表格（弹出选行列数后插入）、分割线；右上角 `MD` 按钮切换「所见即所得 ↔ Markdown 源码」；底部显示「已自动保存 / 保存中…」，保存失败可点击重试。
- **来源**：`gui/src/components/chat/NoteEditor.tsx`

### 7.3 关联

- **是什么**：笔记之间的关联（相关 / 派生 / 冲突 / 支持），显示在编辑区下方「关联 N 篇」，展开可跳转。
- **怎么用**：**关联由 AI 通过 MCP 工具创建**（`note_associate`）；界面上可查看、点标题跳转。同一关系只需建一次（两端都能看到）。
- **来源**：`gui/src/components/chat/NoteEditor.tsx`、`gui/src/services/mcpBridge.ts`

### 7.4 发送到聊天 / 桌面

- **是什么**：把笔记作为引用发给 AI，或作为文本块放到超级桌面。
- **怎么用**：笔记行右键 →「发送到聊天 / 发送到超级桌面 / 删除笔记」；在编辑器里选中文字后右键 →「发送选中文字到聊天」。
- **来源**：`gui/src/components/chat/NotesPanel.tsx`、`NoteEditor.tsx`

### 7.5 多选批量删除

- **是什么**：笔记列表支持多选后批量删除。
- **怎么用**：点「多选」进入选择模式（或用 Ctrl/⌘ 点行），底部出现「已选 N 项 / 删除 / 取消」。
- **来源**：`gui/src/components/chat/NotesPanel.tsx`
