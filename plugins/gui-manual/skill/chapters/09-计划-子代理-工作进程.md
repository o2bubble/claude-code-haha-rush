# 9. 计划 / 子代理 / 工作进程

### 9.1 计划面板

- **是什么**：展示 AI 用 TodoWrite 建立的任务清单与完成状态；下方是「历史计划」（按会话保存的历史记录）。
- **怎么用**：AI 调用 TodoWrite 后自动出现；展开「历史计划」可看往期计划，点会话名查看。没有计划时显示空态提示。
- **来源**：`gui/src/components/chat/PlanPanel.tsx`、`gui/src/stores/planHistoryStore.ts`

### 9.2 子代理面板

- **是什么**：并行子任务（Agent 工具）的列表与完整对话记录。
- **怎么用**：列表显示「N 运行中 / M 总计」与每个子代理的状态（运行中/已完成/失败/已终止）；点条目展开记录（**按需加载**，可「加载更早消息」）；右键有「终止任务 / 复制任务 ID / 复制 Agent ID」。消息里的工具卡片带「子代理」角标，提示可在本面板看完整过程。
- **来源**：`gui/src/components/chat/SubAgentPanel.tsx`、`gui/src/stores/subAgentStore.ts`

### 9.3 工作进程面板

- **是什么**：后台进程总览：IDE Backend、MCP Server、GUI Server 的状态与端口，以及**插件进程**列表；下方还有后台任务（运行中与已完成）。
- **怎么用**：每个服务旁有「重启」按钮（重启后端 / 重启 GUI server）；插件进程有「终止 / 重启」按钮；任务行的 ✕ 可终止。
- **来源**：`gui/src/components/chat/WorkerPanel.tsx`
