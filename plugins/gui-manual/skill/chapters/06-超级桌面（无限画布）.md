# 6. 超级桌面（无限画布）

### 6.1 桌面标签页

- **是什么**：可创建多个「桌面」（各自的画布与内容），顶部标签切换。
- **怎么用**：顶部 ＋ 新建桌面（默认名「桌面 N」）；双击标签**重命名**；标签上的删除按钮删桌面。
- **来源**：`gui/src/components/desktop/DesktopTabs.tsx`

### 6.2 画布导航

- **是什么**：无限画布，可平移、缩放、显示网格、吸附对齐。
- **怎么用**：
  - 平移：**按住空格拖拽**，或**鼠标中键拖拽**；
  - 缩放：工具栏 −/+（中间显示当前百分比）与「重置」；「适应」= 缩放到能看到全部内容；
  - 「定位」= 把视图平移到当前选中的块；
  - 网格 / 吸附 是工具栏上的开关按钮；
  - 撤销 / 重做（↶ ↷）；
  - 工具栏右端的搜索框按标签或内容过滤，**不匹配的块会变暗**（✕ 清空搜索）；
  - 「清空」需**再次点击确认**（按钮变成「确认清空」）。
- **来源**：`gui/src/components/desktop/CanvasToolbar.tsx`、`gui/src/components/desktop/SuperDesktopCanvas.tsx`

### 6.3 内容块（用户可创建 5 种 + 拖入 3 种 + AI 1 种）

- **是什么**：画布上的卡片。用户在工具栏可直接新建：**文本（+ 文本）/ 表格（+ 表格）/ 表单（+ 表单）/ 绘图（+ 绘图）/ 图形（+ 图形，输入 Mermaid）**；拖入或粘贴文件得到 **图片 / 文件组 / @引用**；**图表目前只能由 AI 创建**（工具栏无图表按钮）。
- **怎么用**：
  - 点工具栏对应按钮，新块落在视口中央；空白处右键也能新建（文本/表单/绘图）或「重置视图」。
  - 文本块：双击编辑，右上角「格式」下拉可切 纯文本 / Markdown / 代码语言。
  - 表格块：点单元格直接编辑，`+ 行` 加行、表头 `+` 加列、双击列名改名、列头 ✕ 删列。
  - 表单块：`+ 添加字段` 选类型（文本/多行文本/数字/复选框/下拉/日期/开关/单选/颜色/滑块），⚙ 配置（必填、最大长度、行数、min/max/step、选项），字段可拖拽排序、双击改名、× 删除；填完值可「发送给 Agent」。
  - 绘图块：工具 画笔/矩形/圆/直线/箭头/文字/橡皮，调颜色、线宽、填充、透明度，↩↪ 撤销重做，✕ 清空，「完成」退出编辑。
  - 图形块：双击可打开 Mermaid 编辑弹窗（粘贴/编辑 Mermaid 代码，预览后保存）。
- **来源**：`gui/src/components/desktop/CanvasToolbar.tsx`、`TextItem.tsx`、`TableItem.tsx`、`FormItem.tsx`、`DrawItem.tsx`、`GraphicItem.tsx`、`MermaidDialog.tsx`

### 6.4 项目操作（拖动 / 缩放 / 折叠 / 删除）

- **是什么**：每个内容块有标题栏与右下角缩放手柄。
- **怎么用**：拖标题栏移动（可多选一起移）；拖右下角改大小；标题栏 ⊟/⊞ 折叠展开；× 删除；双击标题**改标签**；右键菜单：发送给 Agent / 在浮动标签打开 / 在新窗口打开 / 置顶 / 删除项目。多选（空白处框选，或 `Ctrl/⌘ + 点击` 加减选中）后可**整组拖动**、按 `Delete`/`Backspace` 批量删除，或右键批量删除 / 批量发送给 Agent / 置顶。
- **来源**：`gui/src/components/desktop/DesktopItemView.tsx`、`SuperDesktopCanvas.tsx`

### 6.5 连线

- **是什么**：在块与块之间画关系线（带锚点吸附）。
- **怎么用**：鼠标悬停到块上，四周出现黄色锚点 → **从锚点拖到另一个块的锚点**即可连线（拖动中顶部有提示「拖到另一个项目的锚点上即可连线 · 按 Esc 取消」）。右键连线可「添加/编辑标签」或「删除连线」。
- **来源**：`gui/src/components/desktop/ConnectionOverlay.tsx`、`SuperDesktopCanvas.tsx`

### 6.6 拖入文件 / 粘贴

- **是什么**：把文件拖进画布或直接粘贴，会按类型生成对应的块。
- **怎么用**：从资源管理器拖文件/文件夹到画布上松手（图片 → 图片块；其余文件与文件夹 → 文件组块，支持多选一次拖入）；或在画布上 `Ctrl+V`（图片 → 图片块；文件/文件夹路径/长文本 → 文件组块；短文本 → 文本块）。
- **来源**：`gui/src/components/desktop/SuperDesktopCanvas.tsx`、`FileGroupItem.tsx`、`ImageItem.tsx`

### 6.7 内容块的缩放与内容缩放

- **是什么**：图片/图形等内容有自己的缩放，与画布缩放互不干扰。
- **怎么用**：在块内容上 `Ctrl/⌘ + 滚轮` 缩放内容、拖拽平移、双击复位（提示文字见块内）。
- **来源**：`gui/src/components/desktop/useContentZoom.ts`

### 6.8 让 AI 操作画布

- **是什么**：AI 可以读写超级桌面（建表格、画图表、写笔记、连线），也能读你发过去的块内容。
- **怎么用**：直接说需求（如「在超级桌面画一个近 5 月费用统计表」）；或右键把块「发送给 Agent」。AI 的 MCP 工具清单见 [`gui-agent-guide.md`](./gui-agent-guide.md)。
- **来源**：`gui/src/services/mcpBridge.ts`、`gui/src/services/desktopSummary.ts`
