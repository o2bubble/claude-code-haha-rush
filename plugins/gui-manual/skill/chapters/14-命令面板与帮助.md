# 14. 命令面板与帮助

### 14.1 命令面板（F1 / Ctrl+Shift+P）

- **是什么**：全局搜索入口，一个框里搜六类东西。
- **怎么用**：`F1` 或 `Ctrl+Shift+P` 打开（编辑器内时编辑器命令置顶）；输入关键词过滤（匹配名称与副标题），`↑`/`↓` 选择、`Enter` 执行、`Esc` 关闭。六组：
  - **面板** —— 开/关面板（按最近使用排序；**含插件带来的面板**）；
  - **AI 命令** —— 技能与提示命令，选中后插入输入框（不自动发送）；
  - **会话** —— 切换会话；
  - **设置** —— 打开设置并**直接跳到对应分类**；
  - **插件命令** —— 插件声明的命令；
  - **编辑器命令** —— 撤销/重做、多光标、查找替换等 Monaco 命令（当前有打开的编辑器时才有）。
- **来源**：`gui/src/components/CommandPalette.tsx`、`gui/src/components/useCommandPalette.ts`、`gui/src/utils/commandPaletteLogic.ts`

### 14.2 帮助面板

- **是什么**：内置图文 + 动画教程：界面布局讲解、工具栏每个按钮的作用、各面板介绍、四段核心流程（AI Agent 对话是什么 / 权限确认 / 工作区与会话 / Profile 与 API Key）、布局系统、Office 三件套、超级桌面与笔记的示例动画。
- **怎么用**：应用菜单 →「帮助」（首启时也有入口）。
- **来源**：`gui/src/components/chat/HelpPanel.tsx`、`gui/src/components/chat/help/`
