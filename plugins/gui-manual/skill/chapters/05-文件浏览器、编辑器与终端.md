# 5. 文件浏览器、编辑器与终端

### 5.1 文件树

- **是什么**：当前工作区的文件树，支持新建、重命名、删除、刷新、排序、显示隐藏文件。
- **怎么用**：面板顶部三个按钮：新建文件 / 新建文件夹 / 刷新（新建后在行内输入名字，Enter 确认）。单击选中、双击打开。排序与隐藏文件在 设置 → 文件管理（按名称/日期/类型，目录始终优先；显示以 `.` 开头的文件）。
- **来源**：`gui/src/components/FileTree.tsx`、`gui/src/components/chat/SettingsPanel.tsx`

### 5.2 文件树右键菜单

- **是什么**：对文件/文件夹的一组操作。
- **怎么用**：右键条目 →「复制（绝对路径）/ 复制文件名 / 复制相对路径 / 复制绝对路径 / 在资源管理器中打开 / 在终端中打开 / 粘贴文件（仅文件夹）/ 发送到超级桌面 / 重命名 / 发送到聊天 / 删除」；空白处右键 →「新建文件 / 新建文件夹 / 粘贴文件 / 刷新」。
  - 「发送到超级桌面」：文件变成 @ref 引用块，文件夹变成文件组块（需已打开至少一个桌面）。
  - 「在终端中打开」：对该目录打开系统终端。
- **来源**：`gui/src/components/FileTree.tsx`、`gui/src/components/ContextMenu.tsx`

### 5.3 打开文件：编辑器 / 预览

- **是什么**：文本文件用 Monaco 编辑器打开（多标签页、语法高亮、行号）；Markdown 可切换预览；`png/jpg/jpeg/gif/webp/bmp/ico/svg/pdf` 自动走预览视图。
- **怎么用**：双击文件树里的文件，或点消息里的路径/`@ref` 链接。Markdown 文件在编辑区右上角有一个「预览 / 编辑」浮动胶囊可来回切；编辑器底部状态条显示完整路径与语言；磁盘上的文件被外部改动时，标签上会提示「磁盘已更新 — 点击刷新」（有未保存修改时先确认是否放弃本地修改）。
- **来源**：`gui/src/components/EditorPanel.tsx`、`gui/src/components/Editor.tsx`、`gui/src/components/FilePreview.tsx`

### 5.4 编辑器

- **是什么**：完整 Monaco 编辑器（VS Code 同款内核），支持右键菜单、多光标、查找替换等。
- **怎么用**：`Ctrl+S` 保存；`F1` / `Ctrl+Shift+P` 打开统一命令面板（编辑器内时编辑器命令置顶，如撤销/重做/多光标/行操作/查找替换）；右键菜单里有「保存文件 / 发送到聊天 / 定位目录树」。字体大小、Tab 宽度、自动换行在 设置 → 编辑器。
- **来源**：`gui/src/components/Editor.tsx`、`gui/src/utils/editorCommands.ts`

### 5.5 编辑器标签右键菜单

- **是什么**：多标签页的管理菜单。
- **怎么用**：右键标签 →「关闭标签 / 关闭其他 / 关闭未修改的 / 关闭全部 / 复制路径 / 定位目录树」。文件不在当前工作区时，「定位目录树」回退为在资源管理器中打开。
- **来源**：`gui/src/components/EditorPanel.tsx`

### 5.6 图片预览

- **是什么**：图片/SVG/PDF 的预览视图，带缩放、平移；图片还带取色器。
- **怎么用**：滚轮缩放、拖拽平移、双击「适应窗口」；工具栏有 −/+、`1:1`（原始大小）、「适应」、🎨 取色（**仅图片**：点图上任意位置取色，弹出色值卡片，点击复制色值）。
- **来源**：`gui/src/components/FilePreview.tsx`

### 5.7 终端面板

- **是什么**：显示 AI 执行的每条命令及其输出（xterm.js 渲染），按命令分标签。
- **怎么用**：每个标签 = 一条 AI 命令（悬停看命令原文），标签上 ✕ 关闭；右上角「清空全部」。想自己敲命令请用系统终端（见 5.8）。历史条数上限与字体大小在 设置 → 终端。
- **来源**：`gui/src/components/TerminalPanel.tsx`、`gui/src/stores/terminalStore.ts`

### 5.8 系统终端

- **是什么**：打开一个**真正的系统终端窗口**（在工作区目录下），用于自己跑命令。
- **怎么用**：点工具栏的终端下拉按钮 → 选 `Command Prompt` / `PowerShell` / `Git Bash`（macOS 只有 `Terminal`）。打不开时状态栏会显示具体错误。
- **来源**：`gui/src/components/Toolbar.tsx`（`TerminalDropdown`）
