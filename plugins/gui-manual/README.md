# GUI 功能手册 (gui-manual)

把 GUI 的**功能手册**放进侧栏面板 —— 界面上能看到的每一样东西，这里都告诉你**在哪、怎么用**。

## 它做什么

- **侧栏面板**：17 章 / 78 个功能点，按功能区组织（聊天 / 布局 / 超级桌面 / 设置…）。
  可搜索（支持搜正文，不只标题）、点目录跳转、跟随亮暗主题。
- **AI 也能查**：同一份手册做成技能 —— 你问「XX 在哪」「怎么用 XX」或者遇到界面问题时，
  AI 会查手册给你**准确的菜单路径**，而不是凭印象猜。

## 怎么用

装好后在工具栏「面板」下拉里打开**功能手册**，或按 `F1` 搜「手册」。

## 两种用法

**你自己找**：打开面板 → 左边搜索框输入关键词（如「快捷键」「工作区」「主题」）→
点结果跳转。搜正文也能命中（比如搜「拖拽」会列出所有支持拖拽的地方）。

**问 AI**：直接说「XXX 怎么弄」就行 —— AI 装了这份技能后，遇到界面相关的问题会去查，
给出的路径是准的。你还可以让它「打开帮助面板」这类一步到位的操作。

## 手册内容从哪来

源是仓库里的 `docs/gui/features.md`，由 `build.mjs` 构建成两份同源产物：
- `manual.html`（本面板）
- `skill/chapters/*.md`（AI 按章读取）

**改了源手册要重跑构建**：`node plugins/gui-manual/build.mjs`

## 已知边界

- 只覆盖 **GUI 自身**的功能。插件带来的能力（截屏 / 操作鼠标键盘 / 浏览器自动化）
  由那些插件自己的文档负责。
- 手册里标了「取决于装了哪个插件」的地方，实际形态以你装的插件为准。
