Claude Code Desktop

本地优先的 AI 编程助手 · 桌面客户端

一个把 AI 编程助手带进桌面工作台的开源项目：在保留命令行形态的同时， 提供一整套可自由布局的图形界面，让对话、代码、终端与文件各归其位。

本项目为开源项目，仅供技术分享与学习交流使用，不作任何商业用途， 与相关商标持有方无任何关联。请在遵守当地法律法规的前提下学习使用。

  • 多面板工作台 —— 聊天 / 编辑器 / 终端 / 文件树各自独立，可拖拽重排、浮动成窗
  • 多模型接入 —— 支持任意 Anthropic 兼容 API，一键切换配置
  • 插件与技能 —— 在线安装，插件可贡献面板、命令与后台进程
  • 本地优先 —— 数据保存在本机工作区，不经过第三方服务

技术栈：Tauri 2 · Rust · React 18 · TypeScript · Bun
